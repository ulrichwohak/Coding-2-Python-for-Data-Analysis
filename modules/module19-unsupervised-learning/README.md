# Module 19: PCA and Clustering

This 75-minute live-coding module uses the World Management Survey. Students construct a
transparent management index, standardize management-practice variables, interpret PCA
loadings and scores, compare explained variance, select a k-means solution, and build
evidence-based cluster profiles.

## Materials

- `unsupervised_learning.ipynb`
- Dataset: `data/raw/wms_course.csv`
- Reconstruction worksheet: `prompts/session05-unsupervised-reconstruction.md`
- Source backbone: Gábor's WMS feature-engineering and PCA material; k-means is a course extension

## Reconstruction exercise

The audit checks scaling, the distinction between loadings and scores, outcome-free
fitting, arbitrary cluster numbers, and unsupported narrative labels.
