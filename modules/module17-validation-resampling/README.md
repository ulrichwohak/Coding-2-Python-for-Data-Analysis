# Module 17: Validation and Resampling

This 38-minute live-coding module introduces an untouched holdout, reproducible
preprocessing, five-fold cross-validation, fold-level variation, and RMSE using an Airbnb
price-prediction case. It establishes the data discipline used for regularization.

## Materials

- `validation_resampling.ipynb`
- Dataset: `data/raw/airbnb_hackney_course.csv`
- Source backbone: Gábor's used-car cross-validation logic applied to the Airbnb case

## Learning outcomes

Students should be able to distinguish validation folds from a final holdout, place learned
preprocessing in a workflow, compare candidate models by cross-validated RMSE, and explain
why repeated holdout inspection invalidates it. The session continues into Module 18.
