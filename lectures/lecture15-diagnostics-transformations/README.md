# Lecture 15: Diagnostics and Transformations

This 35-minute live-coding lecture asks where the hotel model is systematically wrong.
Students use residual plots, a heteroskedasticity test, robust standard errors, nonlinear
distance terms, back-transformation, and influence measures to justify model revisions.

## Materials

- `diagnostics_transformations.ipynb`
- Dataset: `data/raw/hotels_course.csv`
- Reconstruction worksheet: `prompts/session02-specification-diagnostics-reconstruction.md`
- Source backbone: the nonlinear hotel-price and multiple-regression diagnostics cases

## Reconstruction exercise

After Lectures 14 and 15, the class asks an LLM to reconstruct the specification and
diagnostic workflow. The audit checks reference groups, interaction slopes, the difference
between robust uncertainty and misspecification, back-transformation, influence, and
causal language.
