# Lecture 20: Regression Trees

After completing `regression_tree.ipynb`, students should be able to fit a regression tree, tune tree depth, inspect splits, and compare tree and linear models.

## Materials

- `regression_tree.ipynb`
- Dataset: `data/raw/housing_sales.csv`
- Practice: `exercises/session20-regression-tree.ipynb`

## LLM Practice

Use an LLM to propose tree-depth tuning logic, then verify it with cross-validation and a held-out test set.
