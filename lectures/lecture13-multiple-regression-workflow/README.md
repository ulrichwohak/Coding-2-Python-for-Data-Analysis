# Lecture 13: Multiple Regression and Workflow Design

This 35-minute live-coding lecture extends the Vienna hotel model with ratings and star
categories. Students compare specifications, interpret a log outcome, predict a proposed
hotel's price, distinguish confidence and prediction intervals, and use residuals to find
cases that deserve investigation.

## Materials

- `multiple_regression_workflow.ipynb`
- Dataset: `data/raw/hotels_course.csv`
- Reconstruction worksheet: `prompts/session01-regression-reconstruction.md`
- Source backbone: Gábor Békés and Gábor Kézdi's advanced hotel-regression materials and
  Chapter 10 case study

## Reconstruction exercise

After the meeting's human analysis is complete, each student develops their own prompt
specifying the completed steps. The generated plan and code are audited against the
human-built notebooks for units, model sequence, reference categories, intervals,
retransformation, and causal overstatement.
