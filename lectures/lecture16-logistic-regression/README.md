# Lecture 16: Logistic Regression and Classification

This 72-minute live-coding lecture follows the SHARE health case. Students move from
observed proportions and a linear probability model to logit, odds ratios, marginal
effects, probability evaluation, calibration, thresholds, confusion matrices, and ROC AUC.

## Materials

- `logistic_regression.ipynb`
- Dataset: `data/raw/share_health_course.csv`
- Reconstruction worksheet: `prompts/session03-binary-outcomes-reconstruction.md`
- Source backbone: Gábor Békés and Gábor Kézdi's binary-model lecture and Chapter 11 health case

## Reconstruction exercise

The class develops the prompt only after completing the analysis. The audit distinguishes
log odds, odds ratios, marginal effects, predicted probabilities, probability metrics, and
classification metrics while checking that evaluation uses data excluded from fitting.
