# Lecture 12: Simple Linear Regression

This 30-minute live-coding lecture begins the Vienna hotel-pricing case. Students build the
notebook alongside the instructor: define the sample, visualize price and distance, fit a
one-predictor model, interpret its units, and connect fitted values to residuals.

## Materials

- `simple_linear_regression.ipynb`
- Dataset: `data/raw/hotels_course.csv`
- Source backbone: Chapters 7–8 hotel cases from *Data Analysis for Business, Economics,
  and Policy*

## Learning outcomes

Students should be able to explain what the fitted line minimizes, interpret the slope in
dollars per mile, obtain prediction intervals, and distinguish a residual from evidence
that a hotel is genuinely overpriced. Complete the human analysis before using the
[Session 1 reconstruction worksheet](../../prompts/session01-regression-reconstruction.md).
Lecture 13 extends this case in a later meeting.
