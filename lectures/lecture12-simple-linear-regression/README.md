# Lecture 12: Simple Linear Regression

After completing `simple_linear_regression.ipynb`, students should be able to fit, visualize, and interpret a one-predictor linear regression model.

## Materials

- `simple_linear_regression.ipynb`
- Dataset: `data/raw/career_outcomes.csv`
- Practice: `exercises/session12-simple-linear-regression.ipynb`

## LLM Practice

Use an LLM to draft a modeling plan for a single-predictor salary question, then revise the plan by checking the data-generating assumptions, model output, and residual plots.
