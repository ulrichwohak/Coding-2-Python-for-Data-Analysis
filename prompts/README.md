# Human-First Reconstruction Exercises

These six worksheets are used only after the class has completed the corresponding
analysis by hand. Students first describe the workflow in their own words, then develop
their own prompt individually, inspect the resulting LLM reconstruction, and compare it
with the completed notebooks. The class discusses differences across the responses.

The completed human analysis is always the reference implementation. The generated
response is a stochastic comparison object, not course authority. Do not commit generated
responses as canonical solutions.

## Classroom sequence

1. Run the deliberately short initial prompt.
2. Identify what the prompt failed to specify.
3. Each student completes their own improved prompt scaffold.
4. Run the individual revised prompt in the instructor's chosen LLM interface.
5. Execute or inspect the generated code in a separate scratch file.
6. Record differences in vocabulary, workflow, implementation, results, and claims.

Individual LLM use continues in the debugging homeworks. The reconstruction exercise
establishes the verification routine students should use there.
